# VoiceKill 1.0.15-dev.7 安装教程

适用于 Minecraft Java **1.21.11 / Fabric / Java 21**。Fabric Loader 最低 0.17.3，当前 PCL 实例的 0.20.0 满足要求。包不含游戏本体、启动器、Loader 或 Java。

## 包内内容

- VoiceKill dev.7、Fabric API 0.141.6+1.21.11、Architectury API 19.0.1、Shriek 1.1.22，共四个 JAR。
- Zipformer 双语识别、Silero 自然断句、SenseVoice 句末复核、CT Transformer 离线标点，四组模型、9 个文件。
- 配置模板、安装与设置说明、许可证、来源清单和 SHA256 校验。**不含 Vosk 模型**。
- WordBank 沿用用户提供的文件，原始副本位于 `sources/WordBank.java`。

## 安装与更新

1. 关闭 Minecraft。PCL 开启版本隔离时，本实例的游戏目录为 `D:\Program\PCL2\.minecraft\versions\1.21.11-Fabric 0.20.0`；未隔离时以启动器实际设置为准。
2. 将旧 `voicekill-*.jar` 移出 `mods` 备份，再把包中 `game-root/mods` 的四个 JAR 放入。已有同一前置只保留一个兼容版本，避免重复加载。
3. 将 `game-root/voicekill` 文件夹合入游戏目录，最终结构为 `<游戏目录>/voicekill/models/<模型ID>/<文件>`，不要多套一层 `game-root`。已有模型可按清单校验后沿用，但需补齐 `silero-vad/silero_vad.onnx`。
4. 首次安装且没有现成配置时，将 `config-template/voicekill.json` 放到 `<游戏目录>/config/voicekill.json`。**已有配置不要整份覆盖**，以免丢失词库、人名、别名和麦克风设置。
5. 启动游戏，F7 进入设置、F8 选择麦克风。语音识别选 Zipformer，开启自然断句，停顿确认约 0.6 秒、持续讲话兜底约 10 秒，保存并重连麦克风。旧配置中的 5 / 0.35 数值不会因替换 JAR 自动改变。
6. 进入世界或服务器，输入 `/vk start` 开始，`/vk stop` 停止处罚。F8 可停止录音。模型首次初始化仍需等待，状态可在 F8 查看。

本包模板设置 `autoModelDownload=false`、`allowVoskFallback=false`，离线文件齐全时无需再次下载。缺失或损坏时按清单/目录检查；如自行开启自动下载，可在 F7 → 设备与模型 → 模型下载进度查看实际字节进度和校验状态。

## 朋友联机与服务端

服务端与每位客户端都安装同版本 VoiceKill 和三个前置。纯服务端只需四个 JAR，**无需语音模型**；实际开麦的客户端需要模型。单人游戏按客户端步骤即可。

词库、人名、玩法参数及死亡风格由服主管理；麦克风、识别和 HUD 由每位玩家本机设置。服务端网页仅监听服务器本机 `127.0.0.1:38471`，不能通过玩家自己的 localhost 管理远程服务器。

## 这一版怎么用

- F7：统一设置，支持实时字幕及粉红危险词、物品栏危险词换行、排行榜位置、模型进度和死亡文本。
- 死亡风格默认 `friends`，随机使用 20 条整活文案，可切换经典、三个专题或自定义混搭。修改文案后先应用到草稿，再点父页面保存。
- 每次处罚仍显示玩家、危险词和识别原文公告，正式死亡文案另外显示。
- 查看页面和示例预览不触发下载或处罚。实时识别中的临时文字只显示，最终候选才参与处罚。

声学自然断句不等于语法理解，较长停顿或超过兜底仍会拆句。固定合成音频未新增误杀，但仍有原有 MC→ABC 误判和个别 P老板 漏判；真人中文口音、具体 JBL/macOS 设备及多人联机仍需实测。新增进度/死亡编辑页及实际死亡效果尚未完成最新游戏内验收。

详细设置见 `设置详解.md`，证据见 `验证记录.md`。来源和主要文件哈希在 `manifest.json`，全部文件校验见 `SHA256SUMS.txt`。本包不会自动修改你的实例，按以上步骤手动合入。
